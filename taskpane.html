Envio automático: configuração

O botão "Enviar" precisa do ID de uma aplicação registada no Microsoft Entra. Esse ID não é uma palavra-passe nem identifica a tua conta: é o mesmo para todas as pessoas que usam o suplemento. Os emails saem sempre da conta com que inicias sessão. Como registar: README, secção "Envio automático".
